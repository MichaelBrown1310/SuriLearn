# 🎬 Video Promocional — SuriLearn (Remotion)

Proyecto de animación programática desarrollado con **Remotion (`4.0.539`)**, **React 19**, **TypeScript** y **Tailwind CSS v4** para la presentación comercial de **SuriLearn**.

## Escenas (`src/scenes/`)
1. `Scene1Alert.tsx` — El ataque / gancho inicial de phishing.
2. `Scene2Problem.tsx` — El problema de las capacitaciones tradicionales pasivas.
3. `Scene3Solution.tsx` — Presentación de SuriLearn, mascota Suri y mockup interactivo.
4. `Scene4Gamification.tsx` — Pilares de gamificación (XP, rachas, 5 vidas, ligas PYME).
5. `Scene5CTA.tsx` — Cierre y llamado a la acción.

## Renderizado Generado (`out/`)
- `out/surilearn-motion-ad.mp4` — Video final Full HD (`1920x1080`, 30 FPS, 660 frames / 22 segundos).
- Capturas clave: `still-alert.png`, `still-solution.png`, `still-gamification.png`, `still-cta.png`.

## Ejecución Local
```bash
npm install
npm run dev     # Abre Remotion Studio para previsualización interactiva
npm run build   # Empaqueta el proyecto Remotion
```
